Operación limpieza

Byte

RETO A · PNL + MACHINE LEARNING

🏫 Aula en Orden: clasificador de reportes escolares

Situación ficticia: el plantel recibe reportes breves sobre necesidades de mantenimiento, pero cuesta organizarlos. Queremos clasificar cada reporte en una categoría: agua, electricidad, limpieza o mobiliario.

EntradaUn texto breve: “El lavabo del pasillo gotea desde ayer”.
Salida esperadaUna categoría sugerida: “agua”. No determina urgencia ni sustituye una revisión humana.
Dataset80 textos inventados: 20 ejemplos por categoría para probar el flujo.
AprendizajeEtiqueta, TF-IDF, Naive Bayes, predicción y reporte de métricas.

Pasos que debes comprender

  1. Lee el problema y define las cuatro etiquetas.
  2. Inspecciona el dataset: filas, columnas, valores vacíos y duplicados.
  3. Separa los textos (X) de sus etiquetas (y).
  4. Divide los datos: 80% entrenamiento y 20% prueba.
  5. Usa TF-IDF y entrena Naive Bayes dentro de un Pipeline.
  6. Revisa métricas; prueba una frase nueva y explica cuándo el sistema debe pedir revisión humana.
Importante: 80 ejemplos sintéticos sirven para aprender el flujo, no para afirmar que el clasificador será confiable en un plantel real. Para una versión seria harán falta más ejemplos variados, etiquetas revisadas y pruebas con datos nuevos.

RETO B · PNL + SIMILITUD

🎪 ExpoGuía: asistente de preguntas frecuentes

Situación ficticia: durante la Expo de IA, los visitantes preguntan dónde están los proyectos, a qué hora comienzan las demostraciones y qué significa PNL. El equipo crea un pequeño buscador que compara la pregunta nueva con preguntas conocidas.

Entrada“¿Dónde puedo ver los robots?”
Base de conocimientoPreguntas y respuestas verificadas por el equipo y el docente.
ProcesoTF-IDF y similitud coseno para buscar la pregunta más parecida.
SalidaLa respuesta asociada; si la similitud es baja, el sistema reconoce que no sabe.
¿Es igual al Reto A? No. Aquí no entrenamos un clasificador con etiquetas. Recuperamos la respuesta vinculada a la pregunta más parecida. Sigue siendo PNL, pero es un buscador sencillo de FAQ.

Código para Google Colab

Buscador con TF-IDF + similitud coseno

Abre Google Colab, crea un cuaderno y pega el código en una celda.

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

preguntas = [
    "Donde esta el modulo de robotica",
    "A que hora empieza la demostracion",
    "Que es el procesamiento del lenguaje natural",
    "Como puedo conocer los proyectos de los alumnos",
    "Donde puedo consultar el programa de la expo",
    "La entrada tiene algun costo",
    "Que computadoras utilizan para inteligencia artificial",
    "Como funciona un modelo de machine learning"
]

respuestas = [
    "El modulo de robotica esta en la estacion 2.",
    "Consulta el horario publicado en el programa oficial.",
    "Es una rama de IA que permite procesar y analizar lenguaje humano.",
    "Visita las estaciones y conversa con los equipos participantes.",
    "El programa se encuentra en el modulo de bienvenida.",
    "La informacion de acceso debe confirmarse con la organizacion.",
    "Se utilizan equipos preparados segun los recursos de cada proyecto.",
    "Aprende patrones a partir de datos para realizar predicciones."
]

vectorizador = TfidfVectorizer(ngram_range=(1, 2))
matriz = vectorizador.fit_transform(preguntas)

consulta = "Donde puedo ver los robots"
vector_consulta = vectorizador.transform([consulta])
similares = cosine_similarity(vector_consulta, matriz)[0]
indice = similares.argmax()
puntaje = similares[indice]

# Umbral ilustrativo: debe probarse y ajustarse con preguntas reales
umbral = 0.18
if puntaje >= umbral:
    print("Respuesta:", respuestas[indice])
    print("Similitud:", round(float(puntaje), 3))
else:
    print("No tengo informacion suficiente. Consulta al equipo de bienvenida.")
Nota: el umbral 0.18 es solo un valor inicial para experimentar, no una garantía. Cada equipo debe probar preguntas distintas y ajustar el umbral para evitar respuestas equivocadas.
